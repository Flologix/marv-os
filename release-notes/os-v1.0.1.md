Marv OS now tells you when a new version is out.

### What's new

- **A bar says when a newer Marv OS is out**, with What's new and Download buttons. Once a day Marv OS asks GitHub
  which release is the latest; nothing else is sent, and nothing is downloaded or installed for you. Turn it off in
  Settings › About, or with `MARV_NO_UPDATE_CHECK=1`.

### Known issues

- **macOS and Windows builds aren't signed yet**, so each asks once before the first open.

### Feedback

Please report anything that breaks, feels slow or confuses you in the
[issues](https://github.com/Flologix/marv-os/issues).
